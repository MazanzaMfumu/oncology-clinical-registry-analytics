# Privacy and Ethical Considerations

This educational portfolio project uses a public oncology dataset.

The original row-level CSV, prepared individual-level files and local
SQLite database are not distributed through this GitHub repository.

The project does not contain direct hospital patient identifiers.
`case_id` is a technical identifier generated for the reproducible
workflow and is not a medical-record identifier.

Publicly distributed reports and dashboard screenshots contain
aggregated indicators only.

The synthetic fallback dataset used by the Streamlit demonstration does
not represent real patients.

The project is not intended for clinical decision-making, individual
prognosis or official registry reporting.

The dataset license and provenance are documented separately in
`data_source_register.md`.
